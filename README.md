# 🏦 Bank Management System

A simple Python-based Bank Management System developed using
Object-Oriented Programming (OOP).

## 📌 Project Description

This project provides basic banking operations such as:

- Create a bank account
- Login using account number
- Deposit money
- Withdraw money
- Check account balance
- Calculate interest for Savings Account
- Logout

## 🛠️ Technologies Used

- Python
- Object-Oriented Programming (OOP)
- Git
- GitHub
- VS Code
